# MiniHeld — Fabric 1.21.4

Клиентский мод, который уменьшает предметы в левой руке: тотем, эндер-жемчуг и снежок.

## Самый простой способ собрать на ПК

1. Установи Java 21.
2. Установи Gradle или добавь Gradle Wrapper (`gradlew`) в проект.
3. В папке проекта выполни `gradle build`.
4. Готовый `.jar` будет в `build/libs/`.

## Сборка без установки Gradle

Загрузите этот проект в GitHub и откройте вкладку **Actions** → **Build Fabric mod** → **Run workflow**.
GitHub Actions сам установит Java 21 и Gradle и соберёт `.jar`. После завершения открой запуск workflow и скачай артефакт `miniheld-fabric-1.21.4`.

## Настройка

Текущий размер предмета в левой руке задаётся в коде. По умолчанию масштаб — 55%.
